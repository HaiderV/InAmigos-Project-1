# Internship Task 1: InAmigos Foundation NGO Website

This repository contains the complete source code for **Task 1** of my web development internship. The project involved designing and developing a clean, fully responsive, and modern website for **InAmigos Foundation**, built strictly with standard HTML, CSS, and vanilla JavaScript—adhering to custom styling guidelines without heavy framework bloat or artificial gradients.

---

## 🏢 About InAmigos Foundation

**InAmigos Foundation** is a Section 8 registered non-profit organization founded on **September 23, 2020**, by **Mr. Govind Shukla (Founder & CEO)**. Based in Chhattisgarh and operating across India, the foundation actively works towards social empowerment, education, animal welfare, and environmental conservation.

### Key Credentials & Certifications
* **Section 8 Registered Non-Profit** licensed by the Central Government
* **80G & 12A Certified** (Ensuring tax-exempt benefits for donors)
* **CSR-1 Registered** (Collaborating on corporate social responsibility projects)
* **NITI Aayog Registered**
* **IAF ISO 9001:2015 Certified**

### Core Flagship Initiatives
1. **Project Seva:** Food and clothing distribution for the underprivileged.
2. **Project Bachpanshala:** Quality education initiatives for underprivileged children.
3. **Project Jeev:** Animal welfare, rescue, protection, and feeding drives.
4. **Project Udaan:** Women empowerment through skill development and financial independence.
5. **Project Prakriti:** Environmental conservation and tree plantation efforts.
6. **Project Vikas:** Employability and skill development training programs.

## 🛠️ Project Structure & Features

The project consists of a multi-page layout designed with a cohesive color palette (**Primary Navy `#0b1c3d`**, **Accent Orange `#ff5722`**, and **Clean Light Neutrals**).

### Page Breakdown & Sections Created

#### 1. Home Page (`index.html`)
* **Header & Navigation:** Sticky top navigation bar with clean branding and responsive menu options.
* **Hero Section:** High-impact callout with primary action buttons.
* **Get to Know Us (About):** Structured overview featuring key organizational credentials and image showcase.
* **Our Causes & Impact Counter:** Key statistics bar tracking **200+ Volunteers**, **28 States**, **6 Causes**, and **50,000+ Beneficiaries**.
* **Core Team & Volunteers:** A clean 5-column grid featuring team members with styled card designs and role highlights.
* **Events Section:** 3-column event card grid detailing recent drives and awareness programs.
* **Call to Action (CTA):** Dual-card section encouraging community members to join as volunteers or support causes.
* **Contact Us:** Registered address, direct phone/email contacts, and an interactive contact form.
* **Footer:** Comprehensive 4-column footer containing quick links, credentials, contact information, and copyright notice.

#### 2. Gallery Page (`gallery.html`)
* **Pure Image Grid:** Clean 3-column photo gallery showcasing field impact photos without distracting overlays or sloppy gradients.
* **Dynamic Pagination:** Built-in JavaScript array rendering 10 images initially with a **"Load More Photos"** feature that seamlessly loads the next batch of images on demand.

---

## 🚀 Tech Stack Used

* **HTML5:** Semantic structure and accessible markup.
* **CSS3:** Custom Flexbox, CSS Grid layouts, variable-based theme colors, and full mobile-first media query responsiveness.
* **JavaScript (Vanilla):** Dynamic DOM manipulation for image rendering and pagination.
* **Font Awesome:** Clean SVG icon set for UI elements.
